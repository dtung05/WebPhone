# WebPhone - Website Bán Điện Thoại
## Giới thiệu
WebPhone là dự án website bán điện thoại trực tuyến được xây dựng bằng PHP thuần theo hướng lập trình hướng đối tượng (OOP) và sử dụng MySQL để quản lý dữ liệu.
Dự án được thực hiện nhằm tìm hiểu quy trình xây dựng một ứng dụng web hoàn chỉnh từ thiết kế cơ sở dữ liệu, xử lý nghiệp vụ, xác thực người dùng đến quản lý sản phẩm và đơn hàng.
## Công nghệ sử dụng
* PHP, MySQL
* HTML, CSS, JavaScript (core)
## Chức năng chính
### Khách hàng
* Xem danh sách sản phẩm
* Xem chi tiết sản phẩm
* Tìm kiếm sản phẩm
* Đăng ký tài khoản
* Đăng nhập / Đăng xuất
* Thêm sản phẩm vào giỏ hàng
* Đặt hàng

### Quản trị viên
* Quản lý sản phẩm (CRUD)
* Quản lý danh mục sản phẩm
* Quản lý tài khoản người dùng
* Quản lý đơn hàng

## Tính năng kỹ thuật
* Xác thực người dùng bằng Session
* Phân quyền người dùng và quản trị viên
* Kết nối cơ sở dữ liệu bằng PDO/MySQLi
* Áp dụng lập trình hướng đối tượng (OOP)
* Tổ chức mã nguồn theo mô hình MVC cơ bản
* Thực hiện các thao tác CRUD hoàn chỉnh
